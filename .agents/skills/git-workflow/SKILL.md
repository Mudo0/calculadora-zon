## Workflow and skills

Before starting work or GitHub actions, read the applicable skills in `.agents/skills/`:

- `issue-creation` (`.agents/skills/issue-creation/SKILL.md`): when filing issues for out-of-scope bugs, edge cases, or follow-up tasks.
- `branch-pr` (`.agents/skills/branch-pr/SKILL.md`): when creating branches (`<type>/<description>`), writing conventional commits, and opening PRs using `.github/PULL_REQUEST_TEMPLATE.md`.
- `chained-pr` (`.agents/skills/chained-pr/SKILL.md`): when a change exceeds ~400 changed lines and needs splitting or a `size:exception` note.

Follow the project's `AGENTS.md` and `PLAN-IMPLEMENTACION.md` rules first if any skill example conflicts with this repository's setup.
